# LabZero requests

LabZero, projects by CompilingThings.

We build datasets with clear ownership and full provenance, at expert level, in any domain. The framework is the product. MQL5 is the proof of concept.

If you want a dataset built for your field, ask here. [Open a new issue](https://github.com/CompilingThings/labzero-requests/issues/new/choose) and choose the **Dataset request** form. It asks for your domain, what the dataset should teach a model, and how you would judge the result.

Issues in this repository are public. Anyone can read them, so do not post anything confidential. If you have source material, describe it in the form rather than uploading it.

You will get a reply in the issue itself.
